# :wrench: Manual Configuration

You can configure NightlyLauncher either via the UI (recommended) or by manually editing config files.

## :open_file_folder: File paths

NightlyLauncher uses the following files and folders when operating:

### :pencil: Configuration Files

- `%appdata%/NightlyLauncher/config.json`
- `%localappdata%/NightlyLauncher/apps.json`

### :file_folder: Folders

- `%localappdata%/Apps` *(Default value, can be changed)*
- `%localappdata%/Downloads` *(Default value, can be changed)*
